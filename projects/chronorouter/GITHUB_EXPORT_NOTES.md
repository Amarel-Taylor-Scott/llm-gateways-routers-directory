# GitHub export notes

This directory is intended to become its own repository named `chronorouter`.

The GitHub connector used to create this branch did not expose a brand-new repository creation action, so the scaffold was staged here as a self-contained project directory. To make it a standalone repository, create a new GitHub repo named `chronorouter`, then copy the contents of this directory to the repository root.

Suggested repository description:

> Temporal-demand-aware model routing and bounded graph-of-solutions orchestration for LLM and agentic workflows.

`llm`, `agents`, `model-router`, `temporal`, `routing`, `cost-optimization`, `local-models`, `llmops`
